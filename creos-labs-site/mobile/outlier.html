FAQ

Questions.

Which platforms does Outlier support?−

TikTok, Instagram, and YouTube — a single creator can be tracked across any combination of them under one card.

How is the score calculated?+

Against the creator’s own running median views, not a universal benchmark — so a small account’s breakout post scores the same way a large account’s does.

Does it write scripts for me?+

No. It shows you the structure of what worked — hook, beats, hook style — so you can write the next one with that in mind.
